# ⚡🎮 Pokémon Guess Who? 🕹️🔥

Welcome to the ultimate two-player pass-and-play **Pokémon Guess Who?** web application! 🎒✨ Built with React, Vite, and plain CSS, this game lets you and a friend duel head-to-head on a single device to see who can catch (guess) the opponent's secret Pokémon first! 🏆👀

---

## 🌟✨ Features

* 👥 **Pass & Play Action**: Share one device safely with private handoff screens that keep your secrets locked tight! 🤫🔒
* 🎨 **Pokémon Trainer Theme**: Styled with classic Pokéball reds, electric yellow cards, and comic-book vibes! ⚡🔴
* 🎴 **24 Suspect Slots**: Fully responsive grid that scales seamlessly across desktops, tablets, and phones! 📱💻
* ❌ **Interactive Elimination**: Tap any card to cross out suspects with a bold red X—tap again to restore them if you make a mistake! 🔄🎯
* 🖼️ **Smart Image Fallbacks**: Drop JPG photos into `public/characters/` (1.jpg through 24.jpg) or let it automatically display clean numbered placeholders! 🔢📸
* 🚫 **Zero Backend Required**: Runs 100% locally in your browser with no databases, servers, or internet needed after setup! 🚀💨

---

## 🛠️🚀 Quick Start Instructions

Make sure you have **Node.js** and **npm** installed on your computer, then run these commands in your terminal:

```bash
# 1. Clone or open your project folder
cd guess-who-demo

# 2. Install dependencies 📦
npm install

# 3. Fire up the local development server ⚡
npm run dev

```

Open the local link provided in your terminal (usually `http://localhost:5173/`) to start playing! 🎉🥳

---

## 📸🖼️ Adding Your Pokémon Art

Want to use real images instead of the numbered placeholders?

1. Create a folder named `characters` inside your `public/` directory (`public/characters/`). 📁
2. Name your image files exactly **`1.jpg`** through **`24.jpg`**. 🏷️
3. Refresh your browser tab to see your custom sprites in action! ✨🎨
